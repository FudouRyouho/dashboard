# @dashboard/common

Helpers sin dominio utilizados por el `apps/server/` o `packages/integrations/`.

## Estructura

- `src/` — Funciones utilitarias comunes como formatos de fecha, manejo de errores, etc.

## Uso

Este paquete contiene funciones reutilizables que no están vinculadas a un dominio específico del dashboard, como helpers para trabajar con fechas, manejo de errores genéricos, y otras utilidades que pueden ser compartidas entre diferentes paquetes.
